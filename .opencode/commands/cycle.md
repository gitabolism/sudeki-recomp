description: One full work-loop cycle — diagnose, note, smallest host-side change, rebuild, run, record
---

Run one work-loop cycle per AGENTS.md, focused on: $ARGUMENTS
(if blank, take queue item #1 from STATE.md).

Order is fixed:
1. `scripts/doctor.sh` — any FAIL is now the task.
2. Reproduce the current wall with `scripts/run.sh` (default settings)
   unless the last log is < 30 min old.
3. `scripts/new_note.sh` (auto-number) — fill Observed + Hypothesis +
   Planned change BEFORE touching code. One variable at a time.
4. Smallest host-side change only (recomp_manual.c / src/*.c / game/
   data / seeds). NEVER edit src/recomp/gen/. Regenerate via
   scripts/pipeline.sh when seeds changed.
5. `scripts/build.sh` + `scripts/run.sh`, classify, diff vs previous log.
6. Append the Outcome section to the note; update STATE.md (wall,
   hypotheses, queue); commit docs+src (git status first — no game or
   generated bytes); end with: stage, verdict, what moved, next queue.
